ИИ ЗАРОК

Поставщики ИИ.

Кто обрабатывает запросы к ИИ Зароку.

Обновлено 25 октября 2026.

Основной поставщик

Google — Gemini API, платный уровень.

Запросы обрабатываются по условиям Google для обработчиков данных. Google не использует их для обучения своих моделей.

Места обработки определяет Google.

Условия Gemini API ↗

Запасной поставщик

Moonshot AI PTE. LTD., Сингапур.

Подключается, только когда основной недоступен, и только для тех, кто дал на это согласие в приложении.

Может использовать запросы, чтобы улучшать свои модели.

Не используется в ЕЭЗ, Великобритании, Швейцарии, Бразилии и Республике Корея, а также когда страна неизвестна и для запросов в чате Telegram-бота.

Что передаётся

Текст запроса, приложенные файлы и нужная для ответа часть расписания.

Номер учётной записи, IP-адрес устройства и сведения об оплате поставщикам ИИ не передаются.

Если список меняется

Когда список меняется, мы обновляем эту страницу.

Если новый поставщик может обучать модели на данных или находится в другой стране, приложение снова попросит согласие.
