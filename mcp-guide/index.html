ChatGPT

Plan in your usual ChatGPT conversation.

Connect ChatGPT
Server URLhttps://zarok.app/mcp
  1. 1

    Open Plugins

    On the ChatGPT website, open Plugins, choose +, then Add custom MCP server.

  2. 2

    Add Zarok

    Name it Zarok, enter the server URL and choose OAuth, then Create as a plugin.

  3. 3

    Approve access

    Sign in on the Zarok page. Allow plan changes if you want to make edits from chat.

  4. 4

    Start a new conversation

    Select Zarok among your connections and ask for tomorrow’s plan.

Custom MCP availability depends on your account and workspace policies.

Telegram

Open the same Zarok inside Telegram.

Open Telegram
  1. 1

    Open the Zarok bot

    Visit @day_calendar_bot and choose Start. Open the mini app using the bot’s button.

  2. 2

    Link your entries

    In Zarok on your phone, find Connect Telegram in the account section. Follow the one-time link to the bot.

  3. 3

    Check the transfer

    If Telegram already has entries, choose whether to transfer them. Open the day view and check your plan.

This links the bot to Zarok. No MCP URL is needed in Telegram. AI Zarok in the bot requires a Zarok subscription.

Grok Bot

Add your plan to Grok Bot’s tools.

Open Grok
Server URLhttps://zarok.app/mcp
  1. 1

    Open the Bot’s Plugins

    In Grok Bot, open the Bot’s info → Setup → Plugins. Add a custom MCP server.

  2. 2

    Choose Remote HTTPS

    Enter the server URL and use OAuth with your own Zarok account.

  4. 4

    Check the tools

    Ask the Bot for tomorrow’s plan. For a Team Bot, check whose account it uses.

Requires a Grok Bot version with custom MCP plugins. Features and access depend on your version and account.

OpenClaw

Add Zarok as a tool for your agent.

Server URLhttps://zarok.app/mcp
  1. 1

    Add a remote server

    Run this on the computer or Gateway with OpenClaw.

    Terminal
    openclaw mcp add zarok --url https://zarok.app/mcp --transport streamable-http

    Complete sign-in

    Start authorization. In Settings → MCP, use OAuth for this server.

  4. 4

    Check the server

    Check the tools, then ask the agent to show your plan.

    Terminal
    openclaw mcp probe zarok

For self-managed setups. Requires an OpenClaw version with remote MCP and OAuth.

Hermes Agent

A connection for your self-managed Hermes agent.

Server URLhttps://zarok.app/mcp
  1. 1

    Add the configuration

    Add zarok under mcp_servers in ~/.hermes/config.yaml. Keep the rest of your settings.

    ~/.hermes/config.yaml
    mcp_servers:
  zarok:
    url: "https://zarok.app/mcp"
    auth: oauth
  2. 2

    Sign in separately

    Start authorization in a fresh terminal. Use a browser on the computer running Hermes.

    Terminal
    hermes mcp login zarok
  3. 3

    Approve access

    Sign in on the Zarok page. Allow plan changes if you want to make edits from chat.

  4. 4

    Reload the tools

    Return to Hermes and reload MCP connections. Then ask for your plan.

    Hermes Agent
    /reload-mcp

Hermes is optional. Use this connection if you already work with this agent.
